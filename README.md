## ✨ Özellikler

- 🎯 **Tek Tuşla Öneri:** Butona bas, rastgele bir aktivite önerisi al
- 🌓 **Dark Mode Desteği:** Sistem ayarlarına göre otomatik tema değişimi
- 📳 **Haptic Feedback:** Butona basınca titreşim geri bildirimi
- 🎨 **Modern Tasarım:** Gradient arka plan, animasyonlu kartlar
- 📝 **25+ Farklı Öneri:** Yürüyüş, kitap okuma, meditasyon ve daha fazlası

## 🚀 Kurulum

### Gereksinimler
- Node.js 18+
- npm veya yarn
- Expo CLI
- iOS Simulator veya Android Emulator (opsiyonel)

### Adımlar

1. **Projeyi klonla:**
```bash
git clone https://github.com/kullanici/bugun-ne-yapalim.git
cd bugun-ne-yapalim
```

2. **Bağımlılıkları yükle:**
```bash
npm install
```

3. **Uygulamayı başlat:**
```bash
npx expo start
```

4. **Test et:**
   - Expo Go uygulamasını telefonuna indir
   - QR kodu tara
   - Veya `i` tuşuna basarak iOS Simulator'da aç
   - Veya `a` tuşuna basarak Android Emulator'da aç
